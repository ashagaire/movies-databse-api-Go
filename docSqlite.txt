#CGO is a feature in Go that allows Go programs to call code written in C (and C-compatible languages).   
Why does CGO exist?
There are many powerful and mature libraries written in C, for example:
    SQLite
    OpenSSL
    graphics libraries
    system-level libraries
Instead of rewriting all those libraries in Go, Go can call them through CGO.
